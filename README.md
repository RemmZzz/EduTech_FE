# 🎓 EduTech Frontend (React + Vite + TailwindCSS)

## ⚙️ Công nghệ
- React 18, React Router v6
- Vite 5
- TailwindCSS 3 + PostCSS + Autoprefixer
- Zustand (state), Axios (API)

## 🚀 Cách chạy
```bash
npm install
npm run dev
```
Truy cập: http://localhost:5173

## 🗂 Cấu trúc chính
- `src/api/` → Gọi API
- `src/features/` → Module theo tính năng
- `src/components/` → Component tái sử dụng
- `src/layouts/` → Layout trang
- `src/routes/` → Cấu hình route
- `src/store/` → State toàn cục
- `src/utils/` → Tiện ích dùng chung
